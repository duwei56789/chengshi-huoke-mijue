# 示例一：客流下滑

**调用方式**：新建任务 → 输入框敲 `/` 选中「成事获客秘诀」→ 发送下面的提问；或直接描述困境让技能自动触发。

## 用户输入

```
我开包子店，最近客流掉了一半，用成事获客秘诀帮我看看
```

## 技能输出（示意）

> **一句话诊断**：客流掉一半，未必是产品变差，更可能是获客动作分散在多个渠道、没有任何一处形成势能。
>
> **一条元规则**（定律 7 · 势能集中律）：不平均用力，把有限力量集中到决定性的一点；小力可撬大势。
>
> **今天能做的一件事**：只选 1 个渠道（例如门店周边 3 公里的社群），连续测 7 天，每天记录进店人数与来源，这期间不新增其他渠道动作。
>
> **可选原书**：《定位》《流量池》

## 为什么这样答

| 环节 | 依据 |
|---|---|
| 身份识别 | 个体工商户，优先讲「客、钱、人、信」 |
| 卡点定位 | 六步回路第 5 步「借势」，对应场景速查表「客户太少」 |
| 定律选取 | 定律 7 势能集中律 + 获客五环（占心智 / 圈流量 / 选爆渠 / 让人传 / 留得住） |
| 今日小事 | 取「选 1 个渠道测一周」，是单动作、当天可开始，不要求读完一本书 |

## 追问方向

- 「测了一周没起色，帮我看是不是做值那一步出了问题」
- 「周边有三家同类店，怎么写出『我只服务__的__』」

> 说明：示例不含任何虚构的营业额、增长率或客户数，具体数据需由使用者提供真实情况后再判断。
