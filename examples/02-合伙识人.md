# 示例二：合伙怕被坑

**调用方式**：新建任务 → 输入框敲 `/` 选中「成事获客秘诀」→ 发送下面的提问。

## 用户输入

```
准备跟人合伙开第二家店，怕被坑，先用五力律帮我过一遍
```

## 技能输出（示意）

> **一句话诊断**：风险不在「人好不好」，而在没用小成本验证过对方在利、怕、面、群、惯五方面的真实反应。
>
> **一条元规则**（定律 2 · 人性五力律）：所有人恒被利（趋利）、怕（避害）、面（被尊重）、群（从众）、惯（路径依赖）驱动；看人先看这五力，再看承诺。
>
> **今天能做的一件事**：设计一个 3 天内能完成、有明确交付物的小任务交给对方（例如盘一次库存并给出差异清单），观察其交付质量与沟通方式，再谈股权。
>
> **可选原书**：《人物志》《冰鉴》《人性的弱点》

## 为什么这样答

| 环节 | 依据 |
|---|---|
| 身份识别 | 个体工商户，涉及「人、信」 |
| 卡点定位 | 六步回路第 2 步「识人」+ 第 6 步「守信」 |
| 定律选取 | 定律 2 人性五力律；场景速查表「怕被人坑」→「看人看利怕面群惯」 |
| 今日小事 | 场景速查表「合伙/用人」→「用『小任务』测人」；大单前先小合作试水 |

## 追问方向

- 「五力里他『怕』的是什么，我该怎么问出来」
- 「小任务通过了，股权和退出条款该按什么顺序谈」

> 说明：本示例只提供识人框架，不构成法律意见；涉及合伙协议、股权与出资，请咨询专业律师。权谋类内容仅用于识坑自保。
