# 行业案例库 · 诊断模板

> 使用说明：本文件提供「按行业套用七律 / 六步回路」的诊断模板，不含虚构的经营数据。调用时先向用户询问真实情况，再给结论；不得把模板内容当作已验证的实战案例对外宣称。

## 一、通用诊断模板（任何行业先跑一遍）

| 诊断项 | 要问用户什么 | 对应步骤 / 定律 |
| --- | --- | --- |
| 身份与目标 | 你是做什么的？这一程最想要什么？底线在哪？ | 0 定锚 |
| 真实卡点 | 现在最疼的一件事是什么？持续多久了？ | 定位步骤 |
| 客户五力 | 客户图什么利、怕什么、要什么面子、跟谁抱团、习惯从哪买？ | 2 识人 · 人性五力律 |
| 价值主张 | 你稳定解决了谁的什么痛点？凭什么稀缺？ | 3 做值 · 价值交换律 |
| 可复制性 | 哪件重复动作能写成 SOP，不用你也在跑？ | 4 建系 · 系统复利律 |
| 渠道集中度 | 现在铺了几个渠道？哪个能当第一？ | 5 借势 · 势能集中律 |
| 信誉账 | 上一次交付是给信誉加分还是减分？ | 6 守信 · 信任资本律 |

输出固定四段：一句话诊断 → 一条元规则（标注第几条定律）→ 今天能做的一件事 → 可选原书推荐。

## 二、四类高频场景的调阅起点

1. **包子店 / 餐饮小店**：主诉多为「客户太少、复购低」。起点 = 借势 · 获客五环（占心智 / 圈流量 / 选爆渠 / 让人传 / 留得住）；今日小事优先给「选 1 个渠道测一周」这类单动作。
2. **百货店 / 零售门店**：主诉多为「竞争太卷、只能降价」。起点 = 势能集中律；元规则「不做更好，做不同」；今日小事 = 写一句「我只服务___的___」。
3. **英语培训 / 教培**：主诉多为「获客贵、家长不信」。起点 = 信任资本律 + 人性五力；今日小事 = 整理一份可公开的真实交付记录，不做效果承诺。
4. **圈粉后复利（有流量没变现）**：主诉多为「粉丝不少但不赚钱」。起点 = 价值交换律 + 系统复利律；今日小事 = 列出 3 个粉丝明确愿意付钱解决的具体问题。

## 三、行业卡生成格式

为用户生成「__行业 30 天执行卡」时，按四段输出，每段只保留可当天完成的动作：

- 第 1 周：定位卡点（0 定锚 + 2 识人）
- 第 2 周：做值验证（3 做值，找出愿付钱的小痛点）
- 第 3 周：单渠道测试（5 借势，只测 1 个渠道）
- 第 4 周：SOP 与信誉（4 建系 + 6 守信，写成可复用流程）

## 四、红线

- 不虚构营业额、增长率、客户数等「已验证案例」数据。
- 不承诺收益；涉及医疗、法律、具体投资标的时声明「本技能是心法，不是专业建议」。
- 权谋类内容只用于识坑自保，不用于算计他人。
